遊び方・攻略ガイド

当サイトで公開している5つのゲームの遊び方をまとめました。BLADE QUEST ・ 灯火 -ともしび- ・ ねこ捕獲作戦 ・ 浴室清掃員の夜勤 ・ 旗上げビート の攻略ポイントをそれぞれ見ることができます。

BLADE QUEST -剣士の冒険-

横スクロールアクション。基本操作から3ステージそれぞれの攻略のコツ、ボス戦の立ち回りまでまとめました。詰まったらここを見返してみてください。

基本操作

移動← → キー / A・D キー(スマホは画面下の左右ボタン)
ジャンプ↑キー / Wキー / Space キー(スマホは「跳」ボタン)
攻撃Xキー / Jキー(スマホは「斬」ボタン)
スタート/リトライEnter または Space、もしくは画面タップ

攻撃はボタンを押した瞬間に剣を振る形式です。連打すると短い硬直(クールダウン)を挟みながら連続で斬れますが、闇雲に振り回すより「敵の攻撃の隙を見てから当てる」ほうが被弾を抑えられます。

基本の立ち回り

  • 敵に接触するとダメージを受けます。攻撃を当てたあとは少し距離を取って様子を見るのが安全です。
  • ダメージを受けると一瞬無敵になり点滅します。この間に体勢を立て直しましょう。
  • 飛行タイプの敵は上下に揺れながら動くため、ジャンプ攻撃よりもタイミングを合わせた地上攻撃の方が当てやすいです。
  • 射撃タイプの敵は一定間隔で弾を撃ってきます。弾の軌道は水平なので、しゃがめませんがジャンプで避けられます。

第1章 忘れられた森 ― モスグレムリン

森を抜けた先に待つ最初のボス。「突進」を2回続けて行ったあとに、大きくジャンプして着地の衝撃波(左右に広がる)を出す、という行動パターンを繰り返します。突進の予兆(一瞬静止して光る)を見たら攻撃をやめて距離を取り、着地後の隙に斬り込むのが安定します。

第2章 水晶の洞窟 ― クリスタルゴーレム

天井から結晶の破片を降らせる「結晶の雨」と、接近して回転する「スピンアタック」を使い分けてきます。結晶の雨の最中は無理に近づかず左右に動いて破片を避け、ゴーレムがこちらに近づいてきたら早めに距離を取るか、隙を見て一撃離脱を狙いましょう。

第3章 崩れゆく城塞 ― 灼熱の騎士

最終ボスは「突進」「3方向弾の拡散射撃」「雑魚の召喚」をランダムに織り交ぜてきます。画面が忙しくなりますが、拡散射撃は3発とも軌道が読みやすいので、撃った瞬間にジャンプで上の隙間をすり抜けるのがおすすめです。召喚された雑魚は放置せず先に処理すると事故が減ります。

スコアを伸ばすコツ

雑魚敵の撃破で50点、ステージクリアで500点、ボス撃破で1000点が入ります。無理に全ての敵を倒す必要はありませんが、道中の敵をできるだけ処理してからボスに挑むと、被弾リスクを減らしつつスコアも稼げます。

灯火 -ともしび- THE LAST LIGHT

見下ろし型の脱出ホラー。懐中電灯の光と暗闇の駆け引きが中心のゲームです。捕まると章の途中からのやり直しはできず、その場でゲームオーバーになるので注意してください。

基本操作

移動矢印キー / WASD(スマホは画面下の十字ボタン)
懐中電灯Fキー(スマホは「灯」ボタン)。オンオフを切り替えます
息を潜めるShiftキー長押し(スマホは「潜」ボタン長押し)。移動は遅くなりますが見つかりにくくなります
スタート/リトライEnter または Space、もしくは画面タップ

光とバッテリーの駆け引き

  • 懐中電灯をつけると視界は大きく広がりますが、バッテリーは有限で、消耗すると強制的に消灯します。
  • 灯りをつけていると遠くからでも敵に気づかれやすくなります。安全な場所では消しておくのが基本です。
  • 暗闇の中でも、近くに何かがいると目だけがぼんやり見えることがあります。見えたら距離を取りましょう。
  • 道中に落ちているバッテリーを拾うと残量が回復します。鍵を探しながら見つけておくと安心です。

第1章 1階 玄関ホール ― 足音

光にも足音にもそこそこ反応してくる、バランス型の追跡者です。灯りをつけたまま歩き回ると気づかれやすいので、鍵の場所の見当がついたら一度灯りを消して近づく、というメリハリが安全です。

第2章 地下貯蔵庫 ― 闇の中の何か

ほとんど目が見えず、光にだけ強く反応するタイプです。基本は懐中電灯を消したまま、息を潜めてじわじわ進むのが安全。どうしても周囲を確認したい時だけ一瞬だけ灯りをつけて、すぐ消すのがおすすめです。

第3章 屋根裏部屋 ― 目覚めたモノ

普段は眠っていて襲ってきませんが、最後の鍵を手に取った瞬間に目を覚まし、以降はずっと追いかけてきます。灯りの有無は関係なくなるので、隠れることは考えず出口へ向かって走り続けましょう。もし捕まってしまったら、鍵は手元から消えるので、もう一度取りに戻って再挑戦することになります。

その他のヒント

  • 館の中には全部で9枚のメモが落ちています。館の裏事情が少しずつ分かる内容になっているので、探索のついでに集めてみてください。
  • 捕まるとその場でゲームオーバーになり、タイトルからのやり直しになります。安全第一で、無理に急がず進むのがクリアへの近道です。

ねこ捕獲作戦 -HEX LOCKDOWN-

六角形の盤面でねこを追い詰めるパズルゲームです。マウスクリックまたはタップだけで遊べます。

基本操作

壁を置く空いているマスをクリック / タップ
スタート/リトライEnter または Space、もしくは画面タップ、画面左上の「RETRY」ボタン

遊び方

  • プレイヤーが壁を1つ置くたびに、ねこが外周へ向かって1マス動きます。
  • ねこが盤面の一番外側のマスに到達してしまうと、その時点で脱走成功=負けです。
  • ねこがどこにも逃げ道がない状態(外周まで辿り着けない状態)を作れれば、その時点で捕獲成功=勝ちです。
  • ねこは常に最短で外へ出られるルートを選んで動きます。近道を1本ずつ塞いでいくだけでなく、逆側に回り込まれないよう先回りして壁を置くのがコツです。

攻略のヒント

  • 盤面の端から埋めるより、ねこの現在地に近い場所から壁を作り、包囲網を少しずつ縮めていく方が安全です。
  • ねこの通り道を1方向だけ塞いでも、反対側から回り込まれてしまいます。常に全方向への逃げ道を意識しましょう。
  • ゲーム開始時にはランダムでいくつか壁が配置されています。これを利用できないか盤面をよく見てから最初の一手を決めるのがおすすめです。

浴室清掃員の夜勤 -SCRUB TILL DAWN-

事故物件の浴室を舞台にしたスコアリングホラーです。4か所の異変に視点を切り替えながら同時対応し、どこまで生き延びられるかに挑戦します。

基本操作

視点切り替え← ドア / → 鏡 / ↑ 天井 / ↓ 床(スマホは画面下のボタン)
作業クリック / タップ
スタート/リトライEnter または Space、もしくは画面タップ

4つの持ち場

  • 浴室ドア:現れた汚れをクリックすると水をかけ、もう一度クリックするとスポンジでこすります。血の手形は落ちにくい代わりに高得点。血の手形が同時に3つ出現すると即ゲームオーバーです。
  • 浴室鏡:定期的にクリックして「お祓い」をしないと、鏡の奥の女性が近づいてきます。クリックのタイミングでgood/great/perfectが決まり、質が高いほど大きく押し返せます。追いつかれるとゲームオーバー。
  • 浴室天井:クモの巣をクリックして掃除します。時々クモが現れ「叩け!!」の表示中にクリックすると撃破、スコアが入ります。ごく低確率で出現する金色のクモは高得点。
  • 浴室床:落ちている髪の毛をクリックして回収するとスコアが入ります。中にはムカデが紛れており、誤って触るとスコアが減るうえ、しばらく操作不能になります。

攻略のヒント

  • ドアの血の手形と鏡の幽霊は、他の作業をしている間も進行し続けます。天井と床は目を離しても危険はないので、優先すべきはドアと鏡です。
  • 操作不能の間もゲーム内時間は進みます。特にドアと鏡の状況が悪いときに床でムカデを踏むと危険なので、余裕がない時は床の作業を控えるのも手です。
  • 時間が経つほど全体の難易度(汚れの出現速度や幽霊の接近速度)が上がっていきます。長く生き延びるほどスコアも稼ぎやすくなりますが、その分忙しくなります。

旗上げビート -DON'T MISS A BEAT-

テンポ120のビートに合わせて遊ぶ、少し変わった旗上げゲームです。全4レベル、指示に従えなければその場でゲームオーバーになります。

基本操作

白旗の上げ下げ← キー / A キー(スマホは「白」ボタン)。押すたびに上下が入れ替わります
赤旗の上げ下げ→ キー / D キー(スマホは「赤」ボタン)
パンを食べる/決定クリック・タップ / Space キー
一句読め表示された文字列を、お使いの端末で正しく入力

レベルごとの内容

  • レベル1:「白上げて」「赤下げて」のような指示に合わせて旗を操作します。指定された時間内に正しい状態にできないと即ゲームオーバー。
  • レベル2:レベル1に加えて「〇下げないで、パンを食え!!」が登場。パンのボタンが出ている間にタイミングよく押しつつ、旗もその状態を保つ必要があります。
  • レベル3:さらに「〇下げないで、一句読め!!」が登場。表示される「五月雨を集めて早し最上川」を制限時間内に正確に入力しつつ、旗の状態も維持します。入力中はビートを気にする必要はありません。
  • レベル4:レベル3までの内容全部に加えて、テンポが上がり、両方の旗を同時に指定される複合指示も混ざります。

攻略のヒント

  • 「〇下げないで」の指示は、その色の旗をとにかく上げたまま(上げていなければ上げて)維持すればOKです。反射的に下げてしまわないよう注意してください。
  • パンのタイミングはボタン周りのリングが一周する前が目安です。早すぎても遅すぎても失敗になるので、出現から少し待ってから押すと安定します。
  • 一句を入力している間はテンポが止まるので、焦らず正確に打つことを優先してください。
